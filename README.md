
# Python Task Manager

A command-line task management application developed using Python and SQLite. It helps users organize their daily tasks, set priorities and deadlines, track completion status, and manage tasks efficiently through a simple menu-driven interface.

## Features

- Add new tasks with a title and description.
- View all saved tasks.
- Update existing task details.
- Delete tasks.
- Mark tasks as completed.
- Search tasks.
- Filter tasks.
- Sort tasks.
- Set task priorities (High, Medium, Low).
- Set due dates for tasks.
- Identify overdue tasks.
- Store tasks permanently using SQLite.
- Validate user input.

## Technologies Used

- **Python 3** – Core programming language.
- **SQLite** – Database for persistent task storage.
- **sqlite3** – Python module for database operations.
- **datetime** – Handling task deadlines and dates.
- **Git** – Version control.
- **GitHub** – Source code hosting.

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/Jeniva-Khatun/Task-Manager.git
```

### 2. Navigate to the project directory

```bash
cd Task-Manager
```

### 3. Run the application

```bash
python3 main.py
```

## Usage

Run the application using:

```bash
python3 main.py
```

Select an option from the menu and follow the instructions displayed in the terminal.
